# Muntaha Shafique — Portfolio

A personal portfolio website built with pure HTML, CSS, and vanilla JavaScript.
Live showcase of frontend skills, selected projects, and journey as a developer.

## Features 

- Animated preloader with progress bar
- 3D particle network (Three.js) in the hero section
- Custom magnetic cursor with trail particles
- Scroll-reveal animations with blur & slide effects
- Dark / Light mode toggle (persists via localStorage)
- Glassmorphism skill cards with VanillaTilt 3D effect
- Responsive project grid with modal previews
- Contact form via Formspree
- Scroll progress bar + section pill indicator
- Fully responsive — mobile, tablet, desktop

## Tech Stack

| Layer      | Technology                        |
|------------|-----------------------------------|
| Markup     | HTML5                             |
| Styling    | CSS3 (custom properties, grid)    |
| Logic      | Vanilla JavaScript (ES6+)         |
| 3D / WebGL | Three.js r134                     |
| Tilt FX    | VanillaTilt 1.7                   |
| Forms      | Formspree                         |
| Fonts      | Fraunces · Geist · Instrument Serif (Google Fonts) |
